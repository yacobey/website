# Selam CPA

[![Security Scanning](https://github.com/selamcpa/website/actions/workflows/security.yml/badge.svg)](https://github.com/selamcpa/website/actions/workflows/security.yml)

A comprehensive full-stack web application for a CPA firm, offering tax preparation, financial statements, AI-powered financial tools, and advisory services.

## Security

The Security Scanning badge above reflects the current status of the [`security.yml`](.github/workflows/security.yml) workflow, which runs on every push and pull request. It checks for high-severity npm dependency vulnerabilities and performs CodeQL static analysis. Clicking the badge opens the full workflow run history.

> **Setup required:** The badge is configured for `github.com/selamcpa/website`. Before it will display a live status, the repository must be created at that URL and the code pushed. Once GitHub Actions runs the `security.yml` workflow for the first time, the badge will automatically show a passing or failing status. If your repository uses a different owner or name, update the two occurrences of `selamcpa/website` in the badge URL near the top of this file.
