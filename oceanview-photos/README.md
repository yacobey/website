# Oceanview — Booking.com Listing Photos

Property photos for listing Oceanview (South Africa) on Booking.com. Part of the
Azeb project (client: Azeb, aziazieb@gmail.com).

## Folders

- `enhanced/` — Listing-ready versions: color-corrected, brightened, bathroom tiles
  whitened, sharpened, and upscaled 2x to clear Booking.com's 1280x900 minimum.
- `originals/` — The photos as received by text message (August 2, 2026), renamed by
  room. Note: text-message compression reduced these to ~720px wide; if full-quality
  originals arrive by email, re-run the enhancement on those instead.
